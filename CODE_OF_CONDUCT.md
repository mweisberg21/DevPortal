# Code Of Conduct

DevPortal uses a simple contributor standard: be direct, respectful, and focused
on making the project better.

## Expected Behavior

- Be clear and constructive.
- Assume good intent while still being precise about problems.
- Keep technical disagreement focused on evidence and tradeoffs.
- Respect maintainer decisions about scope, UX, and release timing.

## Unacceptable Behavior

- Harassment, threats, or discriminatory language.
- Personal attacks.
- Repeated off-topic arguing after a maintainer has made a decision.
- Publishing private security details before a fix is available.

## Enforcement

Maintainers may edit, hide, or remove comments; close issues or pull requests;
or block contributors who violate this code of conduct.
